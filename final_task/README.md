# Анализ данных о Нобелевских лауреатах

Проект по Python, посвящённый обработке вложенных JSON-данных и исследовательскому анализу информации о Нобелевских лауреатах.

Основной анализ выполнен в Jupyter Notebook. Универсальные функции обработки данных вынесены в отдельные Python-модули. Для работы с данными используются стандартные средства Python без `pandas` и `numpy`.

## Задачи проекта

1. Обработать вложенную структуру JSON, преобразовав данные о лауреатах и премиях в удобный формат.
2. Провести первичный исследовательский анализ (EDA): проверить количество записей, пропуски, дубликаты и идентификаторы.
3. Исследовать три темы:
   - **Статистика по странам:** страны-лидеры, распределение по категориям и динамика по десятилетиям.
   - **Миграция лауреатов:** предполагаемые приток и отток лауреатов, абсолютные и относительные показатели, исторические изменения стран.
   - **Отказы от премий:** случаи отказов и ограничений получения премии, распределение по категориям и типам лауреатов.
4. Визуализировать результаты и сформулировать выводы.

## Структура проекта

```text
final_task/
├── README.md
├── laureates_countries_task.ipynb
├── laureates.json
├── json_dict_processing.py
├── prizes_configs.py
├── laureates_configs.py
├── attribute_manager.py
├── dataset_helpers.py
└── aggregations.py
```

**Назначение модулей:**

- `json_dict_processing.py` — универсальная обработка вложенных словарей с использованием конфигураций.
- `prizes_configs.py` — конфигурация обработки информации о наградах.
- `laureates_configs.py` — конфигурации обработки данных людей и организаций.
- `attribute_manager.py` — добавление вычисляемых атрибутов и разворачивание вложенных списков.
- `dataset_helpers.py` — фильтрация, группировка, расчёт долей, проверка пропусков и идентификаторов.
- `aggregations.py` — функции агрегации: количество записей, уникальные значения, среднее, медиана, минимум, максимум и топ-N.

## Требования

- Python 3.12+
- Jupyter Notebook
- `matplotlib`

Остальная обработка реализована средствами стандартных модулей Python.

## Установка и запуск

Клонировать репозиторий:

`git clone https://github.com/Rabotish/omd.git`

Перейти в директорию репозитория:

`cd omd/final_task`

Создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установить необходимые зависимости:

```bash
python -m pip install jupyter matplotlib
```

Запустить ноутбук:

```bash
jupyter notebook laureates_countries_task.ipynb
```
## Данные

- Файл `laureates.json` должен находиться в рабочей директории вместе с ноутбуком.

- В работе используется локальный JSON, поэтому подключение к внешнему API не требуется.

- Данные представляют собой json-файл о нобелевских лауреатах с вложенными структурами.

## Ограничения анализа

- Для статистики по странам используется современное название страны рождения лауреата или основания организации.
- Для определения страны на момент награждения используются сведения о проживании либо, при их отсутствии, об аффилиации.
- Показатель предполагаемой миграции является приближённым: различия стран могут быть связаны с историческими изменениями границ, а аффилиация не обязательно означает фактический переезд.

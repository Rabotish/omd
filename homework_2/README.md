# ДЗ №2 Функции

## Текст задания
1. Иерархия: для каждого департамента показать, какие команды в него входят.
2. Сводка по департаментам: название, сколько человек, минимальная и максимальная зарплата, средняя по каждому департаменту.
3. То же самое, что в "2", но записанное в csv-файл. Имя выходного файла можно захардкодить(например, константой в начале файла) или передавать опциональным параметром в эту же функцию.

## Входные и выходные данные
**Файл данных `Corp_Summary.csv`**
Содержит выгрузку по сотрудникам: ФИО, департамент, команда, должность, оценка, оклад. Колонки разделены `;`.

- Программа читает файл и по выбранному в аргументах варианту готовит отчёт.
- Основная функция принимает на вход int - номер варианта, остальные параметры - по желанию
- Чтение файла и каждый отчёт вынесены в отдельные функции.

## Особенности выполнения

- добавила выброс исключений в случае, если пользователь хочет прочитать несуществующий файл или имя файла (входного или выходного) написано некорректно, последнее реализовано с помощью регулярного выражения
- во избежание некорректного прописывания пути зафиксировала явное приведение названия файла в путь, добавив каталог и расширение
- в `make_report` атрибут `file_name` не является обязательным и использует значение по умолчанию , прописанное в сигнатуре функции, имя выходного файла также может быть не задано, вариативность задается в условии `number == 3`, нужный эффект достигается за счет того, что '' = false, соответственно для того, чтобы использовать название по умолчанию нужно нажать enter при вводе:
```code
file_name = (
            input('Введите имя выходного файла (./homework_2/data/): ')
            or 'departments_summary'
        )
        report_summary_csv(data, file_name)
 ```
- в `report_summary_csv`  код записи в файл защищен от повторной записи в уже созданный файл через исключение и выданным разрешением на работу с файлом 'x'
- каждая функция содержит аннотацию типов атрибутов и возвращаемого результата, для того, чтобы функция `report_summary` соответствовала проверкам mypy дополнительно фиксировала аннотацию для `departments`
- отчеты сформированы посредством `defaultdict`, в качестве `values` брала `list` и `set` (необходимо, чтобы название каждой команды встречалось единожды)
- при формировании второго отчета добавила проверку - если департамент отдельного сотрудника уже есть в словаре, идем дальше, не производя подсчеты, так как они уже есть в ответе:
``` code
if item[1] in departments:
            continue
```
- при формировании списка зарплат отдела использовала comprehensions и фильтр по совпадению департамента:
```code
salaries = [int(i[5]) for i in data[1:] if i[1] == item[1]]
```
-  добавила в `report_summary` аргумент `show` для того, чтобы можно было переиспользовать при записи в csv словарь, полученный в результате функции, собирающей второй отчет без принта для задания 2.

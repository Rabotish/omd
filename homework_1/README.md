# Дз "Основы работы в Python"


## Текст задания
### 1. Один и тот же товар может лежать на складе в Москве, в Казани или в обоих городах.

**Нужно найти:**

- что можно забрать в любом из двух городов
- что есть только в Москве
- что есть только в Казани
- сколько разных товаров на обоих складах вместе

### 2. Дана история поисковых запросов: каждая строка — один введённый запрос. Повтор в списке значит, что этот запрос ввели ещё раз.

**Нужно найти:**

- сколько всего поисковых запросов в ленте
- сколько раз ввели каждый запрос
- какой запрос вводили чаще всего
- какую долю всех поисков он занимает
- какие запросы встретились один раз

### 3.  Есть список заказов:
- `status` -  статус заказа
  - `delivered` доставлен покупателю
  - `returned` возврат
- `amount` — сумма заказа.

**Нужно найти:**

- на какую сумму оформили возвраты
- кто хотя бы раз вернул заказ
- сколько заказов доставлено покупателю
- средний чек доставленных заказов

### 4. Есть статистика за пять дней работы магазина. У каждого дня число заказов, выручка и число возвратов.

**Нужно найти:**

- выручку за всю неделю
- день с самой большой выручкой
- среднюю выручку на один заказ в каждый день
- дни, где возвратов больше 20% заказов

### 5. Есть список отзывов на товары. На каждой строке — по одному. Данные слегка битые, и названия товара записаны в разном регистре. `id` при этом один и тот же для одного и того же товара. Перед подсчётом приведите названия к одному формату, иначе они будут считаться как разные`.

**Нужно найти:**

- среднюю оценку каждого товара
- худший товар по средней оценке среди тех, у кого хотя бы два отзыва
- сколько отзывов на 1 или 2 звезды
- какую долю всех отзывов они составляют

## Требования

- Python 3.8 или выше.

- Используются только модули стандартной библиотеки Python: collections и itertools.

## Запуск

Клонировать репозиторий:

`git clone https://github.com/Rabotish/omd.git`

Перейти в директорию репозитория:

`cd omd`

Запустить программу из корня репозитория:

`python homework_1/omd.py`

## Входные и выходные данные

Все исходные данные определены непосредственно в файле omd.py.

После запуска программа последовательно выполняет пять заданий и выводит результаты вычислений в консоль.

## Особенности решения

В работе использовались:
-  свойства и методы работы с **множествами** (уникальность, intersection, difference, логические операции), **словарями** (обращения по ключу), **списками** (len, sum, срезы и поэлементное обращение) и **кортежами**.
- различные способы итерирования в зависимости от типа данных.
- объекты из модулей itertools и collections - **Counter** (методы `most_common()` и `items()` ), **groupby** (для просмотра содержимого и манипуляций использовался обход по group и value, в решении учитывается факт того, что объект может быть проитерирован единожды)
- для корректной группировки и при подсчете минимального значения используется sorted
-  comprehentions для компактной фильтрации
